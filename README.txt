Martin: No Filter Fighters — Android WebView wrapper project

WHAT THIS DOES
- Opens the supplied itch.io game in a fullscreen, landscape Android app.
- Requires an internet connection; this does not make the game offline.
- Enables JavaScript and web storage, and keeps the screen awake.
- Controller support depends on Android WebView and the game/browser implementation; test your controller on the target device.

BUILD AN APK
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. In Android Studio choose Open, then select the MartinNoFilterFighters folder.
4. Allow Gradle sync and install any requested Android SDK components (Android SDK 35).
5. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show the APK location. Copy the APK to your Android device and install it.

NOTES
- This is a wrapper, not the original game's source code or assets.
- The game is an unofficial fan game. This project is for personal use; obtain the developer's permission before distributing a repackaged version.
- If the game's host page changes or the host blocks embedded play, the wrapper may need adjustments.
